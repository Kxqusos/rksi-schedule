# Редизайн публичной страницы `/viewer`

Дата: 2026-08-01

## Проблема

Текущая страница `/viewer` перегружена и плохо работает на мобильных:

- В шапке слишком много информации: бренд, крупный H1, диапазон недели + номер недели,
  две карточки-стата (выбранная сущность и счётчик «Занятий: N»).
- Карточка занятия выглядит плохо; на мобилке мета (преподаватель/кабинет) «съезжает».
- Неделя показывается как таблица с колонками-днями (Пн–Сб), что вынуждает
  горизонтально листать таблицу на узких экранах.
- Нет переключателя темы (страница жёстко светлая).
- Есть отдельная кнопка «Обновить», хотя расписание и так грузится после выбора.
- У иностранного языка показываются подписи подгрупп, которые не нужны.

## Приоритет

**Mobile-first.** Качество мобильной версии в приоритете; десктоп следует той же
вертикальной логике, просто по центру с ограничением ширины.

## Цели дизайна

### 1. Общая структура (одна колонка, без горизонтального скролла)

Вертикальный макет на всех экранах, порядок сверху вниз:

1. Минимальная шапка (только переключатель темы).
2. Поле поиска.
3. Вкладки дней (Пн–Сб).
4. Список занятий выбранного дня.

На десктопе — тот же вертикальный поток, отцентрованный с `max-width` (ориентир ~720px).
Горизонтального скролла нет нигде.

### 2. Шапка (минимальная)

- Единственный элемент — **переключатель темы** (иконка солнце/луна), в правом верхнем углу.
- Убираем: бренд, крупный H1, номер недели + даты, отображение имени выбранного,
  счётчик «Занятий: N», обе карточки-стата.
- Чьё расписание открыто, видно из значения поля поиска (оно содержит имя выбранного).

### 3. Поиск

- Одно поле по центру сверху: «Найти группу, преподавателя или кабинет».
- Подсказки появляются по мере ввода (как сейчас): иконка типа + название + бейдж типа.
- После выбора из списка расписание грузится **автоматически** (текущий `useEffect`
  на `[selected, week]` это уже делает).
- Кнопку «Обновить» убираем полностью.
- До выбора — заглушка «Начните вводить группу, преподавателя или кабинет».

### 4. Вкладки дней

- Горизонтальный ряд вкладок Пн–Сб (без воскресенья, как сейчас `weekday !== 7`).
- Показывается один выбранный день; по умолчанию — текущий день недели
  (если сегодня Вс — показываем Пн предстоящей недели, согласуется с логикой
  `currentWeekNumber`, которая уже переключает на предстоящую неделю с воскресенья).
- Ряд вкладок помещается по ширине мобилки без горизонтального скролла (6 коротких
  подписей Пн–Сб).
- Каждая вкладка показывает подпись дня и, при наличии места, дату.

### 5. Карточка занятия (переработанная)

Макет:

```
┌────────────────────────────┐
│ 1 пара        08:30–10:00  │
│ Математика                 │
│ Иванов И.И. · ауд. 305     │
└────────────────────────────┘
```

- Верхняя строка: номер пары слева, время справа.
- Предмет — крупно, отдельной строкой.
- Мета одной гибкой строкой (`flex-wrap`), поэтому ничего не «съезжает» на узком экране:
  преподаватель · кабинет · группа — через разделитель.
- Релевантность: если открыто расписание группы — группу не дублируем; преподавателя —
  не дублируем преподавателя; кабинета — не дублируем кабинет (текущая логика сохраняется).
- **Подгруппы у иностранного языка не показываем.** Убираем подпись «N подгр.» для
  предметов, чьё название содержит «иностран» (то же условие, что
  `_is_foreign_language_subgroup_split` в бэкенде — совпадение по подстроке «иностран»,
  без учёта регистра). Для остальных предметов подпись подгруппы остаётся.
- Пустой день: аккуратная строка «В этот день занятий нет».

### 6. Тема оформления

- Светлая и тёмная темы.
- По умолчанию — системная (`prefers-color-scheme`).
- Кнопка-переключатель меняет тему; выбор сохраняется в `localStorage`.
- Применяется через `data-theme` на корневом элементе; CSS-переменные для обеих тем.
- Шрифт — Inter (уже подключён, хорошая поддержка кириллицы).

## Вне рамок (Non-goals)

- Изменения backend API (`/schedule/public/*`) — данные уже достаточны.
- Изменения админки (`page.tsx`).
- Изменение логики выбора текущей недели (`currentWeekNumber`, роллирование в Вс) —
  сохраняем как есть.

## Затрагиваемые файлы

- `apps/web/app/viewer/page.tsx` — разметка, вкладки дней, автозагрузка, тема, карточка.
- `apps/web/app/globals.css` — стили viewer (`.viewer-*`), переменные тем, мобильные брейкпоинты.
